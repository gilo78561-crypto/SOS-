# SOS DOCTEURS — système d’interface

Sources : affiches fournies et skill UI/UX Pro Max. Recherches CLI exécutées via Python 3.14 pour les soins à domicile et l’accessibilité. Les résultats génériques ont été adaptés à la marque du flyer : vert profond #006B45, vert #087F5B, fond #F5F8F6, texte #172C25, secondaire #53675F, blanc, urgence #B42332.

Web : Manrope et DM Sans auto-hébergées avec licences OFL ; corps 16 px. Android : police système lisible. Grille 4/8, rayons 12–24 px, espaces aérés, icônes cohérentes. Aucune statistique ou recommandation fictive.

Navigation web latérale et compacte sur mobile ; Android avec quatre destinations par rôle. Cibles natives de 48 dp, labels visibles, focus clavier, états vides/chargement/erreur, actions sensibles confirmées. Formulaires progressifs, tarif sur devis, disponibilité non garantie, simulation explicitement indiquée.

La carte se charge après accord ; clavier et adresse manuelle disponibles. La conformité d’accessibilité complète, TalkBack et le rendu Android sur appareil restent à auditer.
